Patrones de diseño responsivo (RWD)

Aprende los patrones clásicos de Responsive Web Design completando plantillas reales, con CSS Grid y Flexbox lado a lado. Desarrollo de Aplicaciones Web · Unidad 2.

Inicio

Antes de empezar · cómo funciona el material

▼
Objetivo de la sesión: maquetar los principales patrones RWD haciendo que el mismo contenido se reacomode en móvil, tableta y escritorio, usando @media, CSS Grid y Flexbox.
Qué necesitas
  • VS Code con la extensión Live Server (para ver los cambios al instante).
  • La carpeta PatronesRWD con las 14 plantillas.
  • Las DevTools del navegador (F12) en modo responsive (icono de celular) para probar tamaños.
Cómo están hechas las plantillas

Cada carpeta tiene index.html (ya con contenido) y css/styles.css con los estilos base. Al final del CSS verás este marcador:

/** CODIGO AQUI **/

Ahí, y solo ahí, escribes tu código del layout. No borres lo de arriba.

Regla mobile-first: el diseño base (sin media query) es para móvil: todo en una columna, apilado. Con @media (min-width: ...) vas agregando columnas para pantallas más grandes.

Base

Las 3 herramientas que usarás

▼
1 · Media query (el interruptor por ancho)
/* Se aplica SOLO si la pantalla mide 768px o más */ @media (min-width: 768px) { .contenedor { /* ...columnas aquí... */ } }
2 · CSS Grid (rejilla en 2 dimensiones)
.contenedor { display: grid; grid-template-columns: 1fr 1fr; /* 2 columnas iguales */ gap: 20px; /* separación */ }
3 · Flexbox (acomodo en 1 dimensión)
.contenedor { display: flex; gap: 20px; } .entrada-blog { flex: 1; } /* cada hijo crece por igual */
Regla mental: Grid cuando defines filas y columnas (rejillas); Flexbox cuando acomodas en una línea (fila o columna).

1 · Dos columnas iguales (lo hacemos juntos)

▼

Dos entradas de blog (.entrada-blog) dentro de .contenedor. En móvil se apilan; desde tableta, dos columnas iguales.

01CSS Grid

Pista: display:grid + grid-template-columns: 1fr 1fr dentro de la media query.

Ver solución
@media (min-width: 768px) { .contenedor { display: grid; grid-template-columns: repeat(2, 1fr); gap: 20px; } }
02Flexbox

Pista: display:flex en el contenedor y flex:1 en cada hijo.

Ver solución
@media (min-width: 768px) { .contenedor { display: flex; gap: 20px; } .entrada-blog { flex: 1; } }

3 · Column Drop

▼

El patrón que va soltando columnas al encoger: escritorio = 3 columnas; tableta = una arriba a todo el ancho y dos abajo; móvil = apiladas. Estructura: main + aside + aside. Usa dos media queries.

07CSS Grid
Ver solución
/* Tableta: 2 columnas (main arriba a todo el ancho) */ @media (min-width: 768px) { .contenedor { display: grid; grid-template-columns: repeat(2, 1fr); gap: 20px; } main { grid-column: 1 / 3; } } /* Escritorio: 3 columnas en una fila */ @media (min-width: 992px) { .contenedor { grid-template-columns: repeat(3, 1fr); } main { grid-column: auto; } }
08Flexbox

Pista: flex-wrap:wrap permite que bajen; controla el ancho con flex-basis.

Ver solución
@media (min-width: 768px) { .contenedor { display: flex; flex-wrap: wrap; gap: 20px; } main { flex-basis: 100%; } aside { flex: 1; } } @media (min-width: 992px) { main { flex: 1; flex-basis: 0; } }

Retos

5 · Retos para quien avance

▼

Sin solución a la vista: aplíca lo aprendido e investiga lo que falte.

  • 11/12 · Layout Shifter — el contenido cambia de orden entre móvil y escritorio. Pista: en Grid usa colocación por líneas o grid-template-areas; en Flexbox usa order.
  • 13 · Mostly Fluid — contenido fluido con max-width en el contenedor y márgenes automáticos; casi no cambia, solo se centra al crecer.
  • 14 · Tiny Tweaks — ajustes mínimos: solo cambian font-size, padding o interlineado por breakpoint (una sola columna siempre).
Extra: reemplaza los breakpoints fijos por flujo líquido con grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)) — ¡se reacomoda solo sin media queries!
Cierre

Evidencia y reflexión

▼
Qué entregar
  • Los styles.css completados de los patrones 01 al 10 (mínimo).
  • Capturas de al menos 3 patrones en móvil y en escritorio (DevTools responsive).
  • Una frase de reflexión: ¿en qué caso te resultó más cómodo Grid y en cuál Flexbox?
Lo que te llevas: el mismo layout se puede lograr con Grid o Flexbox; Grid brilla en rejillas y colocación exacta, Flexbox en acomodos de una línea. Y todo patrón responsivo nace mobile-first.
